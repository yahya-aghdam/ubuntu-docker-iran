# نصب‌کننده Docker برای اوبونتو در ایران

اسکریپتی برای نصب Docker Engine روی سرورهای اوبونتو در ایران. این اسکریپت برای دسترسی بهتر، DNS و مخزن بسته‌های اوبونتو را تنظیم می‌کند، مخزن رسمی Docker را امتحان می‌کند و در صورت در دسترس نبودن آن از مخزن جایگزین علی‌بابا استفاده می‌کند. همچنین آینه رجیستری Docker را روی آروان‌کلاد تنظیم می‌کند.

## پیش‌نیازها

- سرور یا VPS با سیستم‌عامل اوبونتو؛ توزیع‌های دیگر پشتیبانی نمی‌شوند.
- دسترسی کاربر root یا مجوز اجرای دستورها با `sudo`.
- دسترسی شبکه به دست‌کم یکی از آینه‌های اوبونتو و مخزن‌های بسته Docker.

## نصب

مخزن را روی سرور اوبونتو دریافت کنید و اسکریپت را اجرا کنید:

```bash
sudo bash docker_installer.sh
```

اسکریپت فقط روی اوبونتو اجرا می‌شود و این بسته‌ها را نصب می‌کند: Docker Engine، خط فرمان Docker، `containerd`، افزونه Buildx و افزونه Compose.

## تغییراتی که اسکریپت انجام می‌دهد

1. DNS را با استفاده از Shecan، Cloudflare و Google تنظیم می‌کند. اگر `systemd-resolved` فعال باشد، یک فایل تنظیمات برای آن می‌سازد؛ در غیر این صورت فایل `/etc/resolv.conf` را بازنویسی می‌کند.
2. از منابع APT در مسیر `/etc/apt/backup-<timestamp>/` نسخه پشتیبان می‌گیرد و نشانی مخزن‌های اوبونتو را به آینه آروان‌کلاد تغییر می‌دهد. اگر به‌روزرسانی فهرست بسته‌ها از آینه ناموفق باشد، تلاش می‌کند تنظیمات قبلی را بازگرداند.
3. ابزارهای موردنیاز برای افزودن مخزن Docker را نصب می‌کند.
4. ابتدا مخزن رسمی Docker و سپس مخزن جایگزین علی‌بابا را امتحان می‌کند.
5. Docker را نصب و آینه رجیستری آروان‌کلاد را در `/etc/docker/daemon.json` تنظیم می‌کند. همچنین اندازه و تعداد فایل‌های گزارش Docker را محدود می‌کند. اگر این فایل از قبل وجود داشته باشد، نسخه قبلی آن در `/etc/docker/daemon.json.bak` ذخیره می‌شود؛ با این حال، فایل اصلی با تنظیمات اسکریپت جایگزین خواهد شد.
6. سرویس Docker را فعال و راه‌اندازی مجدد می‌کند. اگر اسکریپت را با `sudo` اجرا کنید، کاربر اجراکننده را به گروه `docker` اضافه می‌کند.
7. فعال بودن سرویس Docker را بررسی می‌کند و تلاش می‌کند تصویر `hello-world` را اجرا کند.

> **پیش از اجرا:** این اسکریپت تنظیمات DNS، منابع APT، پیکربندی Docker و سرویس‌های سیستم را تغییر می‌دهد. پیش از اجرا، اسکریپت را بررسی کنید و از مناسب بودن DNS و آینه‌ها برای سرور خود مطمئن شوید. اگر `/etc/docker/daemon.json` تنظیمات مهمی دارد، پس از نصب تنظیمات موردنیاز را از فایل پشتیبان به پیکربندی جدید منتقل کنید.

## پس از نصب

اگر کاربر شما به گروه `docker` اضافه شده است، یک بار از نشست کاربری خارج شوید و دوباره وارد شوید تا عضویت گروه اعمال شود. سپس نصب را بررسی کنید:

```bash
docker --version
docker run --rm hello-world
```

برای بررسی وضعیت و گزارش‌های سرویس Docker:

```bash
sudo systemctl status docker
sudo journalctl -u docker -f
```

اجرای `hello-world` یک بررسی تکمیلی است و شکست آن لزوماً به معنی نصب نشدن Docker نیست؛ ممکن است آینه رجیستری در دسترس نباشد.
